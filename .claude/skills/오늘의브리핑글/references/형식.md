# 오늘의 브리핑 글 형식 (v3)

목적: 네이버 블로그(경제·재테크) 검색 유입. 독자는 반도체·미국 ETF·코인 개인 투자자.

## 발행 시점
- 아침 발행이 기본. 한국은 전일 장 마감 종가, 미국은 간밤(현지 전일) 종가.
- 휴장한 시장은 직전 거래일 종가를 쓰고 "기준 시각"에 날짜와 휴장 사실을 한 줄 적는다(`make_data.py`가 자동).
- 코인은 업비트 조회 시점 가격, 전일 종가는 어제 오전 9시 가격.

## 고정 종목 (이 순서)
- 지수: 코스피, 코스닥, 나스닥, S&P500
- 반도체: 삼성전자, SK하이닉스, 엔비디아(NVDA), SOXX, SOXL(3배)
- 미국 지수·기술 ETF·개별주: SPY, QQQ, QLD(2배), TQQQ(3배), 테슬라, 애플, 스트래티지(MSTR)
- 코인(업비트, 원화): 비트코인, 이더리움, 리플
- 환율·금: 원/달러, 금 선물(달러)
- 배당 ETF·배당주(금요일만): SCHD, JEPQ, QQQI, 코카콜라, 리얼티인컴, KODEX 200타겟위클리커버드콜
- 마이크로소프트·구글·아마존 등은 실적 발표나 큰 이슈가 있는 날만 해당 섹션에 한 줄 추가(사실만).

## 글 순서
제목 → 도입 → 기준 시각 → 1.3줄 요약 → 2.상승·하락 TOP5 → 3.지수 → 4.반도체 → 5.미국 지수·기술주·개별주 → 6.코인 → 7.환율·금 → (금요일) 8.배당 → AI 활용 표기 → 해시태그

- "한 줄 정리" 섹션은 없다(같은 숫자 반복 금지).
- 금 원화 환산 줄은 없다(국내 금 시세와 달라 혼동).
- 번호 제목은 일반 굵은 글씨(번호 목록 아님). 붙여넣을 때 모든 줄이 번호 목록이 되는 문제를 막기 위해서.
- 모든 표의 열은 `종목 | 종가 | 전일 대비 | 1년 최고가 대비` (TOP5 표만 `구분 | 종목 | 전일 대비`).
- 일중 고저가는 삼성전자·SK하이닉스만 본문 한 줄로. 못 구하면 그 줄 생략.
- 용어 설명은 "기준 시각"에서 한 번만("1년 최고가 대비"). 레버리지 ETF 뜻만 해당 목록 아래 한 줄.

## TOP5 규칙
- 대상: 글에 담은 개별 종목·ETF·코인.
- 제외: 지수, 환율, 금, 레버리지 ETF(SOXL·QLD·TQQQ) — 구조상 늘 맨 위·아래라 정보가 안 됨.
- 제목은 "오늘 담은 종목 중 상승·하락 TOP5", 기준 시각이 달라 참고용이라고 적는다.

## 제목
`[그날 크게 움직인 종목 2개와 %] [핵심 한마디] (M/D 시황)` 예: `SK하이닉스 -5.03%, 삼성전자 -4.15% 동반 하락 (11/4 시황)`
"폭락·대박·충격" 같은 자극어 금지. 질문형·전망 금지.

## 문체
- 대화체 해요체("~예요/~했어요"), 짧은 문장, 줄바꿈 자주. 이모지 없음. 쉬운 말.
- 맨 위에 굵은 제목 "오늘의 브리핑"을 둔다(사용자가 고친 샘플 기준). 도입은 "지난 거래일 시장에서 어떤 자산이 얼마나 움직였는지 숫자만 모아 정리했어요." 한 줄과 아래 필수 문구뿐이다. ("정보가 빨라야…/수고스럽지 않도록…" 두 줄은 사용자가 샘플에서 뺐다.)
- **모양(사용자 블로그 스크린샷 기준)**: 글 전체 가운데 정렬. 표는 머리글 연한 회색 배경+굵게, 칸 사이 세로선 없이 행마다 연한 가로선만, 행 높이 넉넉하게, 가운데 정렬. "오늘의 브리핑"은 굵지 않은 일반 글씨. 번호 제목은 굵게(본문과 비슷한 크기). 같은 묶음의 줄은 문단 간격 없이 붙이고 묶음 사이만 띄운다. 쉼표로 이어진 문장이 34자 이하면 줄바꿈하지 않는다.
- **줄바꿈**: 모바일에서 읽기 편하게 한 문장이 약 26자를 넘으면 쉼표 뒤나 띄어쓰기에서 줄을 바꾼다(`build_html.py`가 자동으로 `<br>` 삽입). 표는 그대로.
- 필수 문구: "투자 권유가 아니라 공개된 시세를 옮겨 적은 글이에요." 와 "AI 활용" 표기.
- **사실만**: 숫자와 바로 계산한 값, 단순 비교만. 금지: 원인 추정, 전망, 지지/저항/체크포인트, 매매·비중 조언, 심리 해석.

## 요약 이미지 (`make_image.py`)
- 가로 1408px PNG. 제목 "오늘의 증시 요약 & TOP 5 종목", 오른쪽 위 발행일·요일, 아래에 "한국 M/D 종가 · 미국 현지 M/D 종가 기준".
- 1.오늘 3줄 요약 카드 3장(삼성전자·SK하이닉스 / 美 반도체 ETF SOXL·SOXX / 코인). 방향이 같으면 "모두 올랐어요/내렸어요", 다르면 "방향이 달랐어요".
- 2.상승 TOP5·하락 TOP5 나란히. 종목 옆에 (한국)/(미국)/(업비트). 5개가 안 되면 빈 칸에 "상승 종목은 N개였어요".
- 색은 블로그 본문과 같게 상승 빨강, 하락 파랑. 로고는 쓰지 않고 단순 아이콘(KR·US·코인)만.
- 숫자는 data.json 문자열 그대로. 이미지 날짜가 본문 기준 시각과 다르면 재확인이 FAIL이다.
- 이미지는 발행 때 사용자가 직접 올린다(자동 게시 안 함).

## 해시태그
날짜(`#11월4일시황`) + 그날 크게 움직인 종목 + 대표 종목, 15개 안팎. 매일 날짜를 바꾼다.

## 숫자 검증
- 종가와 전일 종가로 전일 대비 %를 다시 계산한다(`make_data.py`가 하고 `검증.txt`에 원본 값을 남긴다). 코인은 업비트가 주는 등락률과도 대조한다.
- 끝내 못 구한 값은 지어내지 않고 `확인 필요`로 두고, 마지막 보고에 목록으로 알린다.
- 원/달러 환율: 야후 일봉은 서울 마감 기준과 달라 기본은 글에서 뺀다(다음 단계: 한국은행 ECOS API 연동). 확인된 값은 작업폴더 `override.json`에 `{"usdkrw": {"close": 1341.0, "prev": 1346.0}}`로 주면 반영된다.

## data.json 스키마 (make_data.py가 만든다)
```json
{
  "title": "…", "title_candidates": ["…"],
  "intro": ["…"], "basis": ["…기준 시각 줄들"],
  "sections": [
    {"title": "지수", "columns": ["종목","종가","전일 대비","1년 최고가 대비"],
     "rows": [["코스피","5,648.79","-3.59%","-39.81%"]], "commentary": ["…"]}
  ],
  "ai_note": "…", "tags": ["11월4일시황"]
}
```
번호는 `build_html.py`가 섹션 순서대로 붙인다(기준 시각은 번호 없음).
