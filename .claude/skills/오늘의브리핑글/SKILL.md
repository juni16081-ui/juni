# 오늘의 브리핑 글

규칙과 글 구조는 `references/형식.md`(v3)에 있다. 먼저 읽는다. 숫자는 스크립트가 받아 계산하고, 클로드는 제목·도입·해설을 다듬고 검수한다.

## 절대 규칙
1. **사실에만 근거한다.** 숫자와 바로 계산한 값, 단순 비교만. 원인 추정·전망·지지/저항·매매 조언·심리 해석 금지.
2. **지어내지 않는다.** 못 구한 값은 `확인 필요`로 두고 마지막에 목록으로 알린다. 접속 제한이 있는 곳은 우회하지 않는다.
3. 해요체, 쉬운 말, 짧은 문장. 자극어(폭락·대박·충격) 금지.
4. 기존 `블로그` 스킬은 건드리지 않는다.
5. **만들고 나면 재확인 1번은 항상 필수다.** (순서 6번)

## 순서
작업폴더: `C:\Users\user\Claude-Projects\투자브리핑\<YYYY-MM-DD>\` (발행일, 한국 날짜)

1. **수집**: `python scripts/fetch.py --out <작업폴더>` → `raw.json` (고정 종목 24개 + 코인 3개, 1년 최고가 포함. 아침 발행 기준으로 장중 봉은 자동 제외).
2. **데이터 생성**: `python scripts/make_data.py --out <작업폴더>` → `data.json`, `검증.txt`.
   - 배당 섹션은 발행일이 금요일이면 자동 포함(`--dividend on|off`로 강제).
   - 원/달러는 확인된 값이 없으면 이번 글에서 뺀다(기본). 확인된 값이 있으면 `override.json`으로 준다(형식.md 참고).
3. **검수**: `검증.txt`의 확인 필요·주의 항목을 본다. 사용자가 검증 수치를 주면 대조한다. 오늘 실적 발표·큰 이슈가 있는 대형주(MS·구글·아마존 등)는 사실만 한 줄 추가할 수 있다(출처 확인된 것만).
4. **다듬기**: `data.json`의 제목 후보·도입을 다듬는다(숫자는 건드리지 않는다). 제목 후보 3개를 만들어 `title_candidates`에 넣고 추천 1개를 알린다.
5. **HTML**: `python scripts/build_html.py <작업폴더>/data.json <작업폴더>/브리핑.html`
   **요약 이미지**: `python scripts/make_image.py --out <작업폴더>` → `요약이미지.png`(+ `요약이미지.meta.json`). 3줄 요약 카드 3장 + 상승·하락 TOP5 표(상승 빨강/하락 파랑, 로고 없음). 숫자는 data.json 그대로, 제목 아래에 한국·미국 기준일을 적는다. 글 맨 위나 요약 앞에 사용자가 직접 올린다.
6. **재확인 (필수, 빼먹지 않는다)**: 만들고 나면 반드시 1번 다시 확인한다.
   - `python scripts/recheck.py --out <작업폴더>` → `재확인.txt`. raw.json에서 모든 표 값을 다시 계산해 대조하고, 문장 속 %가 표에 있는지, 금지 표현·구조·AI 표기·HTML 일치를 본다. 요약이미지는 파일 유무·data.json보다 새것인지·기준일이 raw.json과 본문 기준 시각 줄과 같은지·TOP5 순위와 %가 재계산과 같은지도 본다.
   - 클로드가 `요약이미지.png`도 직접 열어 글자 겹침·잘림·빈 칸이 없는지 눈으로 확인한다.
   - 클로드가 `브리핑.html`(또는 data.json)을 직접 한 번 읽어 어색한 문장·사실 아닌 표현·기준 시각 설명을 눈으로도 확인한다.
   - FAIL이면 원인을 고쳐 data.json→브리핑.html을 다시 만들고 재확인을 다시 돌려 PASS를 확인한다.
   - 보고에 "재확인 결과(PASS/FAIL)"를 반드시 적는다. 재확인을 못 했으면 완료라고 말하지 않는다.
7. **보고**: 파일 경로(브리핑.html, 요약이미지.png), 제목 후보, 재확인 결과, `확인 필요` 목록, 휴장·기준 시각 특이사항을 알린다.

## 붙여넣기 안내 (사용자에게)
크롬에서 `브리핑.html`을 연다 → 제목 복사 버튼 → 네이버 제목 칸 / 본문 전체 복사 버튼 → 본문 칸. 해시태그는 본문 끝에 들어 있다. 클로드 앱 미리보기에서는 복사가 막힐 수 있으니 크롬으로 연다. 표가 에디터에 어떻게 붙는지는 처음 한 번 사용자에게 붙여 보게 하고 결과를 묻는다.

## 파일
- `scripts/fetch.py` 시세 수집(야후 파이낸스·업비트, 키 불필요)
- `scripts/make_data.py` 표·순위·요약·태그·검증
- `scripts/build_html.py` 네이버 붙여넣기용 HTML
- `scripts/make_image.py` 요약 이미지(PNG) 생성
- `scripts/recheck.py` 만든 뒤 재확인(필수): 표 값 재계산·금지어·구조·HTML·이미지 대조
- `scripts/calc.py` 등락·고점 대비 단독 계산기
- `references/형식.md` 구조·문체·종목 규칙
